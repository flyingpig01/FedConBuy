# VetBuys

Marketplace prototype for Disabled Veterans Business Alliance business transfers, with disabled veteran buyer qualification, transparent financials, verified documents, buyer return analysis, saved listings, and comparison.

## Run

This is a static app.

```sh
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Built

- Home page with hero search, quick filters, buyer eligibility section, buyer services preview, featured deal sections, and industry comparison.
- Marketplace page with compact list/map split view, filters, financial listing rows, DVBA/disabled veteran badges, save, and compare actions.
- Listing detail page with overview, financial snapshot, buyer eligibility, transparency score, buyer return calculator, acquisition services, operations, assets, documents, comparable deals, and verification-gated inquiry flow.
- Buyer services page for disabled veteran verification, SBA readiness, lender matching, seller financing, diligence, legal review, insurance, transition planning, certification support, working capital, and growth planning.
- Buyer readiness page with prequalification inputs, acquisition readiness score, estimated buying power, next-step checklist, and best-fit deals.
- Seller valuation page with SDE multiple estimator, listing readiness score, buyer demand signal, and document-readiness checklist.
- Membership page with free, buyer, verified buyer, concierge, seller, and broker subscription tiers plus alerts/deal-drop positioning.
- Seller listing flow with five steps for basic info, veteran ownership/DVBA status, financials, operations, assets/real estate, and documents.
- Seed data for 20 fake disabled veteran-owned business listings across restaurants, dental/medical, e-commerce, services, manufacturing, and real estate-heavy businesses.
